O HTML fornece a estrutura e os pontos de ancoragem, o CSS descreve todos os estados visuais possíveis, e o JavaScript reage ao usuário decidindo quando cada estado se aplica e criando/removendo conteúdo dinamicamente. A comunicação entre eles acontece por dois contratos simples: os id que o JS usa para achar os elementos, e as classes CSS que o JS manipula para mudar a aparência sem nunca escrever estilo diretamente.
